ONE-TIME NETLIFY SETUP (YOU MUST DO THIS)
------------------------------------------
A server must hold the Firebase Admin SDK service account credentials.
Do NOT put these credentials in index.html or send them to ChatGPT.

1. Firebase Console → Project Settings → Service accounts.
2. Generate a new private key.
3. In Netlify → Site configuration → Environment variables, create:

FIREBASE_SERVICE_ACCOUNT_JSON = the COMPLETE JSON contents of that private-key file
FIREBASE_PROJECT_ID = englishmates-ratangarh-933f1

4. Deploy the site with the included netlify.toml, package.json and netlify/functions/new-admission-notify.js.

5. Open the live website → Owner / Admin Login → sign in.
6. Click/allow Enable Alerts.
7. Use the Test Alert button. You should receive a browser notification.
8. Register a test student from another browser/device.
